# Civic-Issues-Reporting-Portal

Pre requisite:
1) Mongo DB Database
2) Web Browser
3) Visual Studio Code (IDE)
4) Sensor Based System for Water Quality Monitoring

Steps to run project:
1) Download and Extract Datasets (Sent in Mail)
2) Execute model.py and model1.py (to Train models for image processing)
3) Make connection between Laptop and Ardiuno via USB
4) run server via (node server.js)
5) run app.py flask server via (python app.py)
6) run ard_to_mongo.py via (python ard_to_mongo.py)
7) run index.html
